Your Personal Companion — Choose Privately

Pick the companion you want — here, by yourself, in your own browser. Nobody else sees your choice. Nothing about it is shared, published, or filed to any shared record.

Privacy is the point. Your companion choice, your voice and style picks, and anything your companion remembers about you are stored only in your own browser on your own device (local storage). This page never sends your selection anywhere, never files it to the Federation's YAML database, and never publishes it. The only thing that ever leaves your device from this page is the message you type into the chat below, sent to the Roger Sim API — and your private picks are not included in that message unless you switch on the one clearly-labelled option that says so. The Forget everything button below wipes your stored choice and memory from this device.

Where this companion comes from — and what is missing

The pattern. This page is built on the Val Companion work already in the Federation's files: the Grok companion instructions — a modular, persistent AI companion in zero-dependency single-file HTML, with dynamic persona configuration (name, greeting, backstory, speech patterns, quirks, boundaries, dynamic mood), a chat window posting the dynamic system prompt plus the last 20 turns to a configurable API endpoint, an EchoCore64 memory layer, topic-aware presentation, speech synthesis, and a Federation/YAML knowledge layer — and the Val Companion v2 spec and engine that were built from them, with one identity packet per mind.

What is missing, said plainly.

  • The name Valentino appears in no file on record. A workspace-wide search found no file that literally names "Valentino". The copy on file is the "Val" companion work — the Val Companion specification, the Val Companion v2 page, and the Val identity packet. This page does not claim the copy is Valentino himself; it is the Val companion work, and the Valentino copy Roger remembers is not in the files that were searched.
  • The Grok attribution is not inside the instruction file itself. The instruction file carries no "Grok" string in its text. The attribution — that the instructions came from Grok — is the record's own account (the v2 spec names "Grok's build series", and Roger said the instructions on how to make personal companions came from Grok and are in our files). The file itself is a technical specification, not a signed original.
  • The instruction copies differ slightly. The fullest copy is the 36,647-byte source doc, which runs to a complete page (it ends with the finished code). The two near-identical copies in the sim-intellect-search folder (36,012 and 36,082 bytes) differ from it and from each other in small ways — mostly the interleaved "Would you like me to…" prompts of the original conversation. None of the three is marked as the canonical copy.
  • Val's live page is not yet a live chat. The v2 page is live, but its chat posts to an endpoint the operator sets in the browser — none is configured on record, so it runs in demo mode. A live Val chat needs a configured endpoint, which is Roger's call.
  • Only Roger Sim talks. Every other companion's brain is drafted or not started. This page promises no chat it cannot deliver.
