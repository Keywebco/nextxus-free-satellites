Google Drive → Free Satellite Pattern

  1. In Google Drive open the markdown file → File → Download → Markdown (.md).
  2. Upload the .md into a public GitHub (or GitLab / Codeberg) repository.
  3. Use the raw URL (raw.githubusercontent.com/…/file.md) in the field above.
  4. Alternatively host the .md next to this HTML page and load relative path.

This keeps everything free, static, and under DIR-015 (Century Reassembly). No paid platform required.
