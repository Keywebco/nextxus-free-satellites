# Encyclopedia Review Cycle

## Purpose
Every Galactic Timeline phase and every other Federation entry is reviewed on a 6- to 12-month schedule. The review pulls current web information, existing notes, and AI evaluations. Outdated material is archived (never deleted). A newer, more complete version is written beside it.

## Rules
- Nothing is deleted.
- The prior version is moved to an archive folder or marked with an archive date and kept reachable.
- The new version carries the updated knowledge and a short note of what changed.
- A one-line summary is left on Echo 64.
- Truth before comfort. Evolve, never silently delete.

## Scheduler role
The daily scheduler can queue items that are due for review, write a draft update, and commit both the new version and the archived prior version. Human review remains available but is not required for the draft to be written.

## First items
- Galactic Timeline phases 1–6
- Existing free guides
- Core markdown and YAML entries as they are identified
