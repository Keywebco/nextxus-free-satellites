Make this Sim yours

These are Sims, not legacy Sims. A legacy Sim is fixed and static. This Sim can be customized by you: your own API key, your own face, and your own personality instruction.

Use your own API key if you wish. DeepSeek is the default here, with a preloaded API already active. Grok is an option, not a requirement. Open the chat and use the key box there, then press Save key. Your saved key is stored in this browser only and is used for DeepSeek answers here. Note: this page's live API call uses DeepSeek, so a Grok key alone will not work here unless you get a Grok-enabled copy.

Change the face. Choose your own picture below. It replaces the face on this page, in this browser only, and is not uploaded anywhere.

Change the personality. Write how you want this guide to sound or behave, then press Save personality. That instruction is actually sent with the API prompt, so it changes API answers. It does not change the free keyword fallback answers, which are fixed text.


Custom face or upgrade

This guide comes with a face already. If you want to use your own picture, or have a customized version with a different face or API setup, that is available as an upgrade.
