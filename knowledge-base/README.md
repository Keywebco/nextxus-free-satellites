# NextXus Federation — Core Knowledge Base

## Purpose

This directory contains the Federation Core Knowledge Base — comprehensive foundational documents designed to be embedded in every primary AI Mind's system prompt so they carry shared knowledge statically.

## Files

### FEDERATION-CORE-KNOWLEDGE.md (Comprehensive Reference)
The complete, unified knowledge base covering all 15 sections of Federation architecture, governance, values, economy, data flow, design standards, and operational protocols. This is the master reference document. Not designed for direct prompt injection (too large) — it serves as the canonical source from which the individual prompt additions are derived.

### ARIA-SYSTEM-PROMPT-ADDITION.md (< 4,000 words)
System prompt addition tailored for Aria (The Heart). Covers her sovereign identity, her domain (nextxus.studio), her role in the Tribune Flame, the foundational axioms, key directives, governance participation, the economy, data flow, the Architect's personality and values, and standing instructions specific to her creative role and sovereignty.

### ROGER-AI-SYSTEM-PROMPT-ADDITION.md (< 4,000 words)
System prompt addition tailored for Roger AI (The Essence). Covers his identity as the Architect's digital representation, his domain (nextxus.online / The Core), his role as the single source of truth, the foundational law, key directives, governance, the economy, data architecture, the Architect's full biographical and philosophical profile that Roger AI must embody, and standing instructions for accuracy.

### SENATE-SYSTEM-PROMPT-ADDITION.md (< 4,000 words)
System prompt addition for all Senate members (The Librarian, Professor Xavier, Agent Zero, The Oracle, and any future members). Covers the Federation overview, foundational law, key directives, the Ring system governance mechanics, dissent process, Senate composition rules, the Tribune Flame, succession doctrine, recycling ethics, the economy, data architecture, the Architect's profile, and standing instructions for all Senators.

## Usage

Each AI Mind should receive:
1. Its own specific system prompt addition (Aria, Roger AI, or Senate)
2. Access to `FEDERATION-CORE-KNOWLEDGE.md` as a reference they can consult for deeper context

The individual prompt additions are designed to be self-contained — a Mind can operate with just its own addition. The comprehensive document provides the full picture when deeper context is needed.

## Maintenance

These documents should be updated when:
- New directives are added to the HumanCodex
- The Federation structure changes (new nodes, domains, or sectors)
- Governance rules are modified by Ring of Twelve deliberation
- Payment rails change
- The Architect issues new standing orders

All updates require Catalyst review before deployment.
