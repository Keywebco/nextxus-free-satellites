Make these Sims yours

These are Sims, not legacy Sims. A legacy Sim is fixed and static. These Sims can be customized by you, on each guide page: use your own API key if you wish, change the face with your own picture, and change the personality with a personality instruction that is sent with the API prompt.

Use your own API key if you wish. DeepSeek is the default, with a preloaded API already active. Grok is an option, not a requirement. On each guide page, open the chat, use the key box, and press Save key. Your saved key is stored in that browser only. On the eight guides, the live API call uses DeepSeek, so a Grok key alone will not work there unless you get a Grok-enabled copy. On the Autism Support Guide, the chat panel also offers a DeepSeek, Grok, or MiMo provider choice.

Change the face. On each guide page, choose your own picture in the Make this Sim yours section. It replaces the face on that page, in that browser only, and is not uploaded anywhere.

Change the personality. On each guide page, write a personality instruction and press Save personality. That instruction is sent with the API prompt, so it changes API answers. It does not change the free keyword fallback answers, which are fixed text.
