How to publish (free)

  1. Download these HTML files (or the whole folder).
  2. Create a new public GitHub repository (or use an existing one).
  3. Upload the files → Settings → Pages → Deploy from branch main.
  4. Or drag the folder to Netlify / Cloudflare Pages / Tiiny.host for instant free hosting.
  5. Optionally fork the full nextxus-yaml-database repo and add these pages as additional satellites.

All pages pull from the canonical YAML via the official CDN loader. They remain functional even if the lattice is temporarily unreachable because critical directives are embedded.
